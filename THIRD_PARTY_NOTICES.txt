ALPINE LINUX RUNTIME
--------------------

The runtime is based on Alpine Linux 3.23.5 and includes dynamically linked
runtime packages such as musl, BusyBox, libdrm, ALSA lib, Avahi libraries,
OpenSSL, ICU, Python, libgcc, zlib, bash, coreutils, and util-linux.
Each package remains governed by the license recorded in its Alpine package
metadata. These include MIT/BSD/Apache-style licenses and copyleft licenses
including GPL and LGPL.

The exact installed package name, version, and license expression are recorded
in the shipped SBOM. Corresponding source and build recipes for copyleft
packages are distributed in the release third-party-source bundle. See
THIRD_PARTY_SOURCE.md.
